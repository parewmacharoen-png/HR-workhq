## การตัดสินใจสำคัญ
- **พนักงาน 1 คน = 1 record** ผูกหลายบริษัทได้ ห้ามสร้างซ้ำต่อบริษัท
- **หลายทีม**: payroll คิดตามบริษัท ไม่ใช่ทีม · sub-leader คุมแค่ทีมหลัก · หน้าลิงก์เชิญยังเลือกได้ 1 ทีมต่อบริษัท
- **ปิดใช้งานพนักงาน** ใช้สถานะ "พักงาน" ไม่ใช่ "ลาออกแล้ว" และห้ามกด "ลบพนักงาน"
- **เซิร์ฟเวอร์**: ทำระบบให้เสร็จบน Render ก่อน แล้วค่อยย้ายเฉพาะ HR ไป **Hostinger KVM 2 + AWS S3 (สิงคโปร์)** ส่วน treasury และระบบ LINE ไม่ย้าย
- **ห้ามใส่ข้อมูลจริง/เอกสารจริงของพนักงาน** จนกว่าจะย้าย VPS (ไฟล์บน Render หายได้ และยังไม่เข้ารหัสเลขบัตร)
